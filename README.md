# 📚 StudyMate AI

### Your Personal AI Study Assistant

StudyMate AI is an AI-powered study assistant designed to help students learn smarter and revise faster using Google Gemini AI.

## ✨ Features

- 📝 Notes Summarizer – Summarizes lengthy study notes.
- 🧠 Quiz Generator – Generates practice questions from notes.
- 💡 Concept Explainer – Explains difficult topics in simple language.
- 📖 Flashcard Generator – Creates flashcards for quick revision.

## 🛠️ Technologies Used

- Python
- Streamlit
- Google Gemini AI
- Google GenAI SDK

## 🚀 How to Run the Project

1. Clone this repository.
2. Install the required packages:

   pip install -r requirements.txt

3. Create a `.env` file in the project folder.
4. Add your Gemini API key:

   GEMINI_API_KEY=your_api_key_here

5. Run the application:

   streamlit run app.py

## 🔐 Security

Never share or upload your actual Gemini API key. Keep it inside the `.env` file.
